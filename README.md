# Arcade Megamania

Tributo retro ao clássico **Megamania** do Atari 2600 desenvolvido em arquivo único (HTML5 Canvas + Vanilla JavaScript puro), sem bibliotecas externas e sem arquivos de mídia adicionais.

## Funcionalidades
- **Mecânicas Clássicas**: Nave com movimentação horizontal fluida, projéteis verticais rápidos (máximo de 2 simultâneos).
- **Sistema de Energia**: Barra de energia que esvazia gradualmente e serve como temporizador da onda, alterando dinamicamente entre verde, amarelo e vermelho.
- **Inimigos em Ciclo**: 5 visuais inspirados no jogo original (Hambúrgueres voadores, Bolachas/Biscoitos, Ferros de passar roupa, Gravatas-borboleta e Diamantes).
- **Efeitos Sonoros**: Sintetizados via código usando a Web Audio API (lasers agudos, explosões e arpeggios de vitória).
- **Pixel Art 8-bit**: Sprites e fonte desenhados pixel a pixel no Canvas.
- **Controles**: Suporte a teclado (setas / A-D + Espaço) e controles touch na tela para dispositivos móveis.
